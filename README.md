# GammaPage SCP — downloads

Release files for **GammaPage SCP**, the desktop DICOM receiver for nuclear medicine workstations.

Download the latest Windows app from the [Releases](../../releases/latest) page: a portable
`.exe` (no install) or a `.zip`. Check a download against `SHA256SUMS.txt`.

The builds are unsigned: on first run Windows SmartScreen asks you to confirm
(**More info** → **Run anyway**).

GammaPage SCP is a workflow aid for qualified personnel, not a diagnostic device. This repository
only hosts release files; it contains no source code and no patient data.
